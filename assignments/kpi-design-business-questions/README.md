## 🔑 Key Concepts

Before you start, explore these essential KPI design patterns:

**1. SMART Criteria - Defining Good KPIs**
```
A good KPI is:
- <!--exercise:answer=Specific,hint=What makes a KPI clearly defined?--> (clearly defined)
- Measurable (has numeric value)
- Achievable (realistic target)
- Relevant (tied to business goal)
- Time-bound (has deadline)

Example: "Increase monthly active users by 15% within Q2"
```

**2. Leading vs Lagging Indicators**
```
Leading indicators predict future performance:
	- Number of sales calls made
	- Website traffic growth

<!--exercise:answer=Lagging,hint=What type of indicator measures past results?--> indicators measure past results:
	- Quarterly revenue
	- Customer churn rate
```

**3. Guardrail Metrics - Checking for Unintended Consequences**
```
When optimizing one metric, monitor guardrails:

Primary KPI: Reduce customer support ticket resolution time
Guardrail: Customer satisfaction score (ensure quality doesn't <!--exercise:answer=drop,hint=What happens to quality if you rush resolutions?-->)
```

**4. Question Tree Structure - From Observation to Action**
```
Diagnostic: What happened? (e.g., "Why did churn increase?")
Predictive: What will happen? (e.g., "Which users are at risk?")
<!--exercise:answer=Prescriptive,hint=What type of question recommends actions?-->: What should we do? (e.g., "Which retention offer works best?")
```
