# 📘 Assignment: Level 13 - KPI Design and Business Questions

## 🎯 Objective

Translate business goals into measurable KPIs and define analysis questions that guide useful decisions.

## 🔗 Builds On

- `Level 6: Data Analysis`

## 🚀 Unlocks Next

- `Level 16: Data Storytelling Memo`

## ⏱️ 20-Minute Chunk Plan

- `13.1` (20 min): Define business objective and stakeholder context.
- `13.2` (20 min): Draft KPI formulas and guardrail metrics.
- `13.3` (20 min): Build question tree for decisions.
- `13.4` (20 min): Validate KPI feasibility with sample data.

## 📝 Tasks

### 🛠️ KPI Blueprint (`BA`)

#### Description
Design a KPI sheet that links business goals to measurable indicators.

#### Requirements
Completed program should:

- Define at least 3 KPIs and 2 guardrail metrics.
- Document formula, owner, cadence, and data source.
- Explain one KPI tradeoff and risk.

### 🛠️ Analytical Question Tree (`Both`)

#### Description
Turn each KPI into actionable questions that analysis can answer.

#### Requirements
Completed program should:

- Create a question tree with at least 8 questions.
- Tag questions as diagnostic, predictive, or prescriptive.
- Add required data columns for each question.

## 🏆 Achievement Evidence

To mark this assignment complete, submit:

- `Code Artifact`: A script or notebook that computes at least one KPI from sample data.
- `Interpretation Artifact`: KPI design sheet with rationale.
- `Verification Artifact`: Output table showing KPI calculations and validation checks.
